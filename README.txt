H.J notes — 한국경제 AI 교육 포트폴리오

article.html : 기사 페이지 (기사 읽기 팝업)
image.html : 이미지 갤러리 (작업 노트 팝업)
video.html : 영상 기획 / 스토리보드
final.html : 최종 프로젝트 소개
index.html : 기본 시작 페이지 (기사와 동일)
style.css : 전체 디자인과 모바일 레이아웃
app.js : 팝업 동작
assets/creative.jpg : 임시 콘셉트 이미지

사용법: ZIP 압축을 푼 뒤 article.html 또는 index.html을 브라우저에서 엽니다. 폴더 구조를 유지하세요.
수정법: 각 HTML의 제목과 본문을 수정하세요. 기사 팝업 본문은 app.js의 articles에서 수정합니다. 이미지 파일은 assets에 추가하고 HTML의 img src를 변경하세요. 실제 영상은 video.html에 video controls 요소 또는 제공받은 임베드 코드를 추가하세요.

정적 HTML 템플릿입니다. 브라우저 파일 업로드 / 서버 저장 / 관리자 로그인은 포함하지 않습니다.
모든 본문은 임시 예시이며 영상은 제작 전 기획안입니다. 콘셉트 이미지는 AI로 생성했습니다.
외부 웹 폰트가 로드되지 않으면 기본 serif 글꼴로 표시됩니다.
